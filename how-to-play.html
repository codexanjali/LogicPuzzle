DOC. LPA-08 — RULES OF PLAY

How to Play

Five modules, five rule sets — presented the way you'd read the rules page of a printed manual. Nothing below is interactive gameplay.

MODULE 01 — DEDUCTION / GRID LOGIC

Sudoku Lite

  1. Read the grid. Some cells arrive pre-filled and locked; the rest are open.
  2. Select an open cell, then enter a value with the number controls or keyboard.
  3. Watch for conflicts. A value repeated in its row, column, or box is flagged immediately.
  4. Fill every cell without conflicts to complete the puzzle and reveal your time and score.
MODULE 02 — SPATIAL RECALL

Memory Grid

  1. Study the grid of face-down cards briefly shown at the start.
  2. Flip two cards per turn to test whether they match.
  3. Matches stay revealed; non-matches flip back after a short delay.
  4. Clear the grid in as few moves and as little time as possible.
MODULE 03 — PATTERN RECOGNITION

Sequence Puzzle

  1. Watch the pattern as it lights up in order.
  2. Reproduce it exactly, in the same order, once it's your turn.
  3. Each correct round adds one more step to the sequence.
  4. One wrong step ends the run — your highest round becomes your score.
MODULE 04 — SPATIAL REASONING

Sliding Puzzle

  1. Tiles start shuffled around a single blank space.
  2. Slide a tile next to the blank space to move it into place.
  3. Only adjacent tiles can move — plan a few steps ahead.
  4. Arrange every tile in order to solve, tracked by move count and time.
MODULE 05 — LINGUISTIC RECONSTRUCTION

Word Scramble

  1. A word's letters are shown jumbled, drawn from a category word bank.
  2. Type or arrange the letters to reconstruct the original word.
  3. Stuck? An optional hint reveals one letter at a small score cost.
  4. Submit the correct word to advance to the next round.
